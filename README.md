# Dago · instaladores

Aquí solo se publican los **instaladores** de Dago (Windows y Android). El código está en un repositorio privado.

- **Windows:** `Dago-<versión>-Windows-instalador.exe`
- **Android:** `Dago-<versión>-Android.apk`

Dago **necesita una licencia** para funcionar: el código de activación lo da el creador de Dago.

Dago instalado **se actualiza solo**: avisa cuando hay versión nueva, la descarga (se reanuda si se corta el internet), verifica que sea la oficial y respalda tus datos antes de instalar.

Cada versión trae su `SHA256.txt` para comprobar que el archivo no fue modificado.
